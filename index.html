But wait… where did that booking actually GO?

Nowhere. The website happily threw confetti… but nobody wrote the booking down. No email was sent. The restaurant has no idea you are coming!

Why? Because a pretty page is only one layer of a real web app. The button looked like it worked — but there was nothing behind it to do the actual work.

Let's meet all the layers that make a website truly come alive.
